# Usage Guide

## Try it with Codex: Question Mode

```text
Read EngineerOS/AGENTS.md and investigate the commerce-risk workspace.

Explain how duplicate open alerts are prevented.

Use authoritative project code as the primary source. Inspect relevant curated
knowledge only as supporting context. Distinguish facts from inferences. Cite
repository paths for important conclusions. Report missing evidence. Do not
modify files and do not create a ticket.
```

## Try it with Codex: new fictional ticket

```text
Read EngineerOS/AGENTS.md and begin Ticket Mode Stage 1 for a new fictional
commerce-risk requirement stored under the applicable ticket source directory.

Trace the requirement, inspect authoritative source and relevant curated
knowledge, state the requested outcome without designing a solution, and record
facts, inferences, assumptions, conflicts, and unresolved questions. Keep
Sample-Projects/commerce-risk read-only. Stop with human confirmation Pending.
```

Replace the workspace and ticket paths for future projects. The generic layout
is `EngineerOS/workspaces/<workspace>/` plus `Sample-Projects/<project>/`.
